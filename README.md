## `> ABOUT ME`

I am a final-year **Computer Science and Engineering** student at **ISEC** (expected graduation: June 2027) and a aspiring **Full-Stack Developer with a strong emphasis on Backend Engineering and Systems Architecture**. While I build complete end-to-end web applications, my core strength lies in designing robust backend services, RESTful APIs, relational databases, and concurrent low-level systems. Currently, I am actively expanding my focus into **Cloud Infrastructure, AI/LLM Integrations, and Mobile Development**.

- ⚙️ **Backend & Systems Core:** Designing scalable APIs, business logic, and multi-process architectures using **Spring Boot**, **Java**, **Node.js**, **C/C++**, **PostgreSQL**, and **Linux/POSIX IPC**
- 💻 **Full-Stack Web Engineering:** Building reactive, decoupled frontends with **React.js (Vite)**, **TypeScript**, and **Figma** that integrate seamlessly with backend microservices
- ☁️ **Expanding Horizons (Cloud, AI & Mobile):** Developing AI-powered features with **LLMs (Google Gemini API)**, cloud-backed services (**Supabase**, **Docker**, **CI/CD**), and native/cross-platform mobile apps (**Kotlin**, **Flutter**)
- 🚀 **Engineering Practices:** Experienced with **Scrum**, **4-stage GitLab pipelines**, **ADRs**, **OOP Design Patterns**, and **JUnit** testing

### 1. [myMenu — AI Smart Recipe Generator (ShiftAppens Hackathon)](https://github.com/JoaoBarao18/MyMenu)
> **Main Full-Stack Developer & UI/UX Designer** · `TypeScript` `Supabase` `PostgreSQL` `Gemini Flash API` `Figma`
- Led end-to-end full-stack architecture and UI/UX design in **Figma** and **TypeScript** under a **48-hour** hackathon deadline to build a smart kitchen web app reducing household food waste.
- Integrated the **Google Gemini Flash LLM** with a cloud **Supabase** backend (PostgreSQL + Google OAuth) to dynamically generate tailored recipes based on pantry inventory, allergies, and portion sizes.

### 2. [Deep Sea Mining — Multi-Phase Strategy Desktop Game](https://github.com/JoaoBarao18/DeepSeaMining)
> **Backend Domain Logic & OOP Architecture** · `Java` `JavaFX` `JUnit` `Design Patterns`
- Architected a **4-phase** strategy desktop game in **Java/JavaFX** applying **5 OOP Design Patterns** (*Facade, State, Factory, Singleton, Multiton*) to strictly decouple core domain logic from the GUI and manage **3 autonomous drones**.
- Implemented asynchronous property-change observers, binary state serialization, and **JUnit** test suites (minimum **2 test cases per core class**) for thread-safe rendering and persistence.

- Co-engineering a **22-feature** web platform using **Spring Boot** and **React.js (Vite)** to centralize exam banks and deliver automated, criterion-by-criterion open-answer evaluations via **LLM** integration, plus a **4-tier** progressive hint system.
- Enforcing code quality across a **6-member Scrum** team over **5 sprints** using a **4-stage GitLab** pipeline (`feature → dev → qa → main`), Architecture Decision Records (**ADRs**), and mandatory Peer Reviews.

### 4. [Concurrent Delivery Dispatch System (ENTREGA-SO)](https://gitlab.com/so8210041/trabalhopratico) *(GitLab)*

- Built a **4-process** distributed system in **C (Linux)** using POSIX system calls, **Named Pipes (FIFOs)**, and anonymous pipes to orchestrate real-time order pricing and dispatch for up to **20 concurrent couriers** and **30 parallel orders**.
- Engineered non-blocking deadline expiration and **10-second** dead-client heartbeat detection using **Unix Signals** (`SIGINT`, `SIGTERM`) and mutex synchronization to eliminate race conditions and zombie processes.
